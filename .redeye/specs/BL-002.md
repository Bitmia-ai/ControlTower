# BL-002: Fix Live tab showing nothing

## Summary

The Live tab at `/project/{id}/live` shows a blank/unhelpful state when no RedEye session is active. The page immediately attempts an SSE connection which fails, leaving the user with "Disconnected" status and "No events yet..." with no guidance.

**Root cause:** The Live page (`app/project/[id]/live/page.tsx`) unconditionally opens an EventSource to `/api/projects/{id}/stream`. When no session is running, the SSE endpoint tails a non-existent JSONL file, the connection eventually errors, and the user sees a near-blank page with no actionable information.

**Fix:** Add session-awareness to the Live page. When no session is running, show a clear empty state. When a session IS running, connect SSE as before and verify events render.

## Architecture

- The project API at `/api/projects/{id}` already returns `running: boolean` and `sessionStatus` -- the Live page fetches this but only uses it for the project name.
- The `TranscriptViewer` component already handles empty events with "No events yet..." but this is insufficient as an empty state.
- The SSE stream endpoint (`/api/projects/{id}/stream`) works correctly -- it tails `session-cto.jsonl` and polls if the file doesn't exist. No backend changes needed.
