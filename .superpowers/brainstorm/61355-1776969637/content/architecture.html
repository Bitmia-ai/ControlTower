Key Decisions

✓ Card grid layout — mission control per project
✓ Structured JSON streaming — claude --print --stream-json
✓ Writes via Claude (Sonnet) — backlog, steer, inbox answers
✓ Fully stateless — no database, reads .redeye/ files
✓ Detached processes + .jsonl — cloud-ready architecture
✓ No iterations in UI — show what, not how
✓ Answer modal with context — suggested answers from RedEye
✓ One instance per project — simple, no multi-instance

Pages

/ — Global mission control. Card per project: name, current task, health, pending questions count.
/project/:id — Project mission control. Card grid: working on, health, questions, up next, recently shipped, steering, controls.
/project/:id/backlog — Full backlog view. Add items, reorder, change priority.
/project/:id/history — Full changelog + activity log.
/project/:id/live — Live transcript stream (debugging/progress view).
